# AI usage

AI tools were used to assist in implementing the design and architecture I provided, including coding, test harness development, documentation, and code reviews. Codex helped translate the design into working code, while Context7 was used to verify PostgreSQL locking behavior, Ponytail helped keep changes focused and review the implementation, and Understand Anything helped update the architecture flow. All AI-generated suggestions were reviewed, modified where necessary, and validated through manual checks and automated testing. The final implementation decisions, architecture, and acceptance criteria remained mine.
